# 营业执照注销助手 - 每日工作引导

一个专为营业执照注销业务设计的内容营销每日引导小程序。

## 功能特性

- 📅 **每日选题推荐** - 智能推荐今日发布选题
- ✅ **任务打卡系统** - 6步每日任务，连续打卡激励
- 📝 **内容模板库** - 短视频脚本、图文笔记模板
- 💬 **话术库** - 评论引流、私信话术一键复制
- 📊 **数据统计** - 记录每日数据，追踪成长

## 技术栈

- HTML5 + CSS3 + JavaScript
- LocalStorage 本地数据存储
- 响应式设计，适配移动端

## 部署

本项目已部署到 Vercel，访问地址：https://your-domain.vercel.app

## 使用说明

1. 打开网页即可使用
2. 所有数据保存在浏览器本地
3. 支持添加到手机主屏幕，像APP一样使用

## 本地开发

```bash
# 克隆项目
git clone <repo-url>

# 进入目录
cd daily-guide-app

# 启动本地服务器
npx serve .
```

## 目录结构

```
├── index.html    # 主页面

```
